# Davranış Kuralları

Bu proje [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
davranış kurallarını benimser ([Türkçe çeviri](https://www.contributor-covenant.org/tr/version/2/1/code_of_conduct/)).

Özetle: herkese saygılı davranın, yapıcı eleştiri yapın, taciz ve ayrımcılığa yer yok.
Kabul edilemez davranışları depo sahibine GitHub üzerinden (@necmettincimen) özel olarak bildirin;
tüm bildirimler gizli tutulur.

This project follows the Contributor Covenant 2.1.
