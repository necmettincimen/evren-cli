# Güvenlik Politikası

## Desteklenen sürümler

Güvenlik düzeltmeleri yalnız en son yayınlanan sürüm için çıkarılır.

## Açık bildirme

Lütfen güvenlik açıklarını herkese açık issue olarak **açmayın**. Bunun yerine
[GitHub Security Advisory](https://github.com/necmettincimen/evren-cli/security/advisories/new)
ile özel olarak bildirin. Bildirimde etkilenen sürümü, yeniden üretme adımlarını ve olası etkiyi yazın.

İlk yanıt için hedef 7 gündür; doğrulanan açıklar düzeltme yayınlandıktan sonra duyurulur.

## English

Please report vulnerabilities privately via GitHub Security Advisories (link above), not public issues.
